## Important source corrections
ScentRadar's directory gives a conflicting concentration for some products. The official product pages were followed and used instead:
- Bleu Glace: official page says Extrait de Parfum, 100 ml (the directory page text says EDP).
- Desert Rose: official page says Extrait de Parfum, 100 ml (the directory page text says EDP and 85 ml).
- Mocha Latte: official page says Extrait de Parfum, 100 ml (the directory page text says EDP).
- Rasayel Vid: official page says Extrait de Parfum, 100 ml (the directory page text says EDP).

This is why the catalog stores official product-page URLs and why the directory was not treated as the final authority.
