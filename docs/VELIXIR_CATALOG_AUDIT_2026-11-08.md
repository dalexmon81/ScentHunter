# Velixir catalog audit — 2026-11-08

## Result

The brand's own online store currently lists 28 individual Velixir perfumes. ScentHunter already contained all 28 names, but the seed had no variant records for this brand. This update adds **52 verified size variants**:
- 24 Eau de Parfum identities with 35 ml and 100 ml variants (48 variants).
- 4 Extrait de Parfum identities — Comus, Ether, Orpheus and Panacea — with 100 ml variants (4 variants).

The official store also lists a Discovery Set. It is a sample set, not a separate perfume identity, and is not imported as a fragrance.
