# Official detail and variant reconciliation — 8 November 2026

## Scope
This PR upgrades provenance and documents explicit variants for Velixir and Khadlaj. It does not add canonical perfume identities: every product reuses an existing product_id.

## Catalog counts
- Canonical identities: 2,061 before and after.
- Explicit variants: 291 → 347 (+56).
- Velixir: 28 existing identities linked to individual official product pages; 24 EDP products receive two explicitly documented sizes (35 ml, 100 ml); the four Extrait pages have no confirmed size selector in the inspected detail pages, so no size variant is inferred.
- Khadlaj: 12 existing identities linked to individual official product pages; eight gain one documented variant; four already had a size variant and receive only the detail-page evidence URL.
- No prices, stock, availability, shipping costs, GTINs or retailer offers are added.

## Evidence rules
Product source_url and source_evidence_url now reference individual official product pages. Each variant created or upgraded carries source_evidence_url. Only explicit sizes/concentrations are recorded. No unsupported commercial fields are added.

## Validation
The regression suite checks individual official source URLs, evidence status, exact sizes and concentrations, variant provenance, global ID uniqueness, and absence of commercial-offer fields. It is included in the catalog-seed validation workflow.
